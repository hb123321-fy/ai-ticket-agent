# AI 研发支持工单 Agent

> 一个能自动分析研发问题、检索知识库、调用工具、生成处理方案，并在关键操作前请求人工确认的 AI Agent 系统。

---

## 项目简介

开发人员在遇到接口报错、服务异常、发布失败等问题时提交工单，系统通过 AI Agent 自动：

- 判断信息是否完整，不足时追问
- 检索知识库和相似历史工单
- 调用只读工具（服务状态、发布历史等）
- 生成包含依据和风险的处理方案
- 高风险操作请求人工确认后执行

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python + FastAPI |
| 前端 | Vue 3 + TypeScript |
| 数据库 | 内存模拟（可替换为 SQLite） |
| AI | 模拟 LLM（可接入真实模型） |
